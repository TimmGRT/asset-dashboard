This project is an interactive asset analysis dashboard built with Streamlit and yFinance.
It allows users to explore market data, visualize technical indicators, and perform basic financial analysis in a clean web app.

Features

* Price Data Download via yFinance (cached for speed)
* Customizable Time Windows for historical data
* Technical Indicators:
- RSI (Relative Strength Index)
- EMA (5, 20, 50)
- ATR (Average True Range)
- Chaikin Money Flow
* Market Analytics:
- Sharpe Ratios (Ticker, Sector, Market)
- Correlation with benchmarks
- Volume Profile (POC, VAH, VAL)
- VIX & Volatility overlay
* Data Export (CSV / Excel)
